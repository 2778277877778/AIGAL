# AIGAL

> 派生自 [2778277877778/gal](https://github.com/2778277877778/gal)，沿用其 MIT 许可（见[许可](#许可)）；原仓库「高中校园物语」的提交历史完整保留。

**同一座高中，每一局都是不同的故事。** AI 写过程和台词，代码管数值和结局。

Ren'Py 校园视觉小说 + 日程数值，简体中文，13+，首版只做 Windows。单局 60–90 分钟，8 回合（高一学年，一回合一个月），1 个 TRUE 结局 + 1 个 END 结局（含 3 种正文变体）。无内购，玩家自填 API key，成本自付。

游戏本体暂时沿用原版名（`config.name = "高中校园物语"`），仓库名是 AIGAL。完整设计见[策划方案_AIGAL_v1.md](高中校园物语/策划方案_AIGAL_v1.md)，那份是唯一权威；README 只做入口，冲突时以方案为准。

## 它是什么，不是什么

- **是**：保留原版《高中校园物语》的校园日程玩法。每月 3 点行动点，去教室、图书馆、琴房、礼堂，推数值、触发事件、应对考试，最后走到两个结局之一。
- **是**：把固定剧本换成每局现场生成的叙事层。这一拍发生什么、谁说了什么、选项怎么措辞，每局都不一样。
- **不是**：聊天机器人。没有无限输入框，玩家仍在**有限选项**里选择，交互骨架不动。
- **不是**：把剧本整个交给模型自由发挥。模型一旦能写数值和结局，多结局就不可控。
- **不是**：本期解决美术的项目。立绘、背景沿用纯色占位，后期补。

## 五条铁律

冲突时按序号优先：

1. **判定链不进 AI。** 数值、Flag、考试、结局只走 `game/systems/stats.rpy`。AI 输出里没有数值字段。
2. **骨架固定，内容随机。** 第几回合、第几拍、几个选项由代码定；拍内事件、台词、选项措辞随机。seed 在月初一次性掷好并存档。
3. **无 key 也能玩。** 降级不是补丁，是一等公民，本地模板库必须覆盖全流程。
4. **AI 文本是外部输入。** 一律清洗后再进 `say`，不清洗等于让网页内容直接控制游戏。
5. **美术后置。** 任何逻辑不得依赖立绘/背景，占位图必须能跑通全流程。

## AI 输出契约

只接受这四个字段，**没有数值字段**：

```json
{
  "lines":   [{"speaker": "zm", "text": "…"}],
  "choices": [{"text": "…", "action_key": "study"}],
  "flags":   ["heard_piano"],
  "mood":    "quiet"
}
```

- `action_key` 必须 ∈ `ACTIONS`；`choices` 为空时走默认选项。
- `flags` 只认该拍的 `allowed_flags` 白名单，且要求 `beat.turn == store.turn`；`TRUE_FLAGS` 与 `confession` 对 AI 拉黑；只 `set` 不 `unset`。
- `speaker` ∈ `mc / zm / zzb / zeng / stu_a / stu_b / inner`，其余一律丢弃。
- 单拍 `lines` ≤8 条，单条 ≤120 字，整段 ≤600 字；每拍输入 ≤3000 token、输出 ≤800。

## 运行

需要 Ren'Py 8.5.3 SDK，解压版即可，不用装进系统；SDK 自带 Python 3.12，不用另装 Python、pip 或第三方包，详见[依赖.md](依赖.md)。下面 `<SDK>` 是 SDK 目录，`<仓库>` 是仓库根目录。

```powershell
# 启动游戏
"<SDK>\renpy.exe" "<仓库>"

# 提交前检查
"<SDK>\lib\py3-windows-x86_64\python.exe" renpy.py "<仓库>" lint

# 生成 .rpyc
... renpy.py "<仓库>" compile

# 冒烟自测
... renpy.py "<仓库>" test

# 打包 Windows 版
... renpy.py "<仓库>" distribute
```

环境细节、沙箱里的存档目录设置、数值系统的函数说明，都在[开发环境说明.md](开发环境说明.md)。

注：现在跑起来不需要联网。AI 层落地后运行需要联网调 API（OpenAI 兼容端点，可配 `base_url` / `model` / `key` / `temperature` / `timeout`），`依赖.md` 里「运行时不联网」那句届时一并改。

## 约定

- 数值只走 `stats.rpy` 里的函数，剧情里不写 `$ study += 5`。
- 剧本先写成 markdown，标好 bg / bgm / sfx、选项和 Flag，再转 `.rpy`。
- key 一律英文小写 snake_case。改一个 key 要同时改三处：`变量命名规范_v1.md`、`stats.rpy`、回合事件表 §3 §5。
- 回合内的选择变量写成 `t<回合号>_<含义>`，值用小写英文，在 story 文件顶部 `default` 一次，不要放进 `flags`。`flags` 只放那 13 个正式 Flag。
- AI 文本入库顺序定死：`filter_text_tags(t, allow=())` → `[` 转义成 `[[` → 最后替换 `{name}` → 截断。顺序反了，`{name}` 会被当标签清掉。
- 玩家自定义主角名先 sanitize：1–8 字，禁 `[` `{` `}` 和换行。名字里带这些字符就是二次注入。
- 线程的 Job 对象不进 `store`（存档会报 `cannot pickle _thread.lock`），只存 int id，Job 表放模块级。12 秒硬超时，连 3 次失败本会话转离线；`config.skipping` 为真时只读缓存或模板，不发现场请求。
- 缓存 key 含 `schema_ver` / `prompt_ver` / `turn` / `beat_id` / `seed` / `choice_path`；`store.ai_log`（进存档）优先于 `persistent.ai_seen`（跨档，200KB 封顶）。
- API key 不写进日志：一律打码，请求体只留长度和前 200 字。
- 主角名暂用 `XXX`，定稿后全仓替换一次。
