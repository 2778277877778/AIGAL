# AIGAL

> 派生自 [2778277877778/gal](https://github.com/2778277877778/gal)，沿用其 MIT 许可（见[许可](#许可)）；原仓库「高中校园物语」的提交历史完整保留。

Ren'Py 校园视觉小说，简体中文，13+，首版只做 Windows。由固定剧本版「高中校园物语」改造而来：剧情文字交给 AI 生成，人物、界面、数值系统沿用原版，仍然带有多结局。游戏本体暂时沿用原版名（`config.name = "高中校园物语"`），仓库名是 AIGAL。

## 改造方向

- **AI 代替固定剧情**：每一拍的场景、台词、选项由 AI 现场生成，不再逐句读死脚本。
- **判定链不进 AI**：`game/systems/stats.rpy` 仍是四项数值、行动点、13 个 Flag、考试线和结局判定的唯一入口。AI 只负责「把这一拍说出来」，不碰数值，不碰结局。
- **事件随机化**：骨架（第几回合、第几拍、几个选项）是固定的，拍内内容随机。
- **玩家自填 API key**：密钥在运行时由玩家自己填，不进仓库。默认存 `persistent`（明文落在存档目录，设置界面会提示），另可选「仅本次会话」不落盘。
- **UI 不变**：沿用原版的标题、对白、选项、地图界面。
- **主角自定义名字**：原版暂用 `XXX` 占位，改造后由玩家输入。
- **立绘与背景**：本期不做，沿用代码里的纯色占位，后期补。

## 进度

现在能跑的是原版固定剧情那条线：从主菜单一路打到 T1 九月的月底结算（报到、开学典礼、军训、班委选举，加 3 点行动点的自由行动段），T1 结束回主菜单。T2 十月已搭好骨架，含通用自由行动段，剧本内容未写。版本号 `0.0.1-demo`。

AI 这一层**还没写代码**，只有设计稿，四个文件都未建：

| 文件 | 职责 |
|---|---|
| `game/ai/provider.rpy` | 发请求、线程、超时与熔断 |
| `game/ai/director.rpy` | 拼 prompt、校验 AI 返回、降级 |
| `game/ai/cache.rpy` | 缓存与预取 |
| `game/ai/schema.rpy` | 输出结构校验、AI 文本清洗 |

动这一层之前先看这几条硬约束：

- AI 只返回 `lines` / `choices` / `flags` / `mood`，永不返回数值。`action_key` 必须属于 `ACTIONS`；`flags` 只认 beat 白名单，且要求 `beat.turn == store.turn`，防止提前 call 到后面的拍。
- `TRUE_FLAGS` 只有脚本能置位；`confession` 对 AI 拉黑。
- AI 文本入库顺序定死：清标签 → `[` 转义成 `[[` → 最后替换 `{name}`。玩家自定义的主角名要先 sanitize，名字里带 `[` 或 `{` 就是二次注入。
- 线程的 Job 对象不进 `store`（存档会报 `cannot pickle _thread.lock`），只存 int id，Job 表放模块级。12 秒超时，连 3 次失败本会话转离线；`config.skipping` 为真时不发现场请求。
- 缓存 key 含 `schema_ver` / `prompt_ver` / `turn` / `beat_id` / `seed` / `choice_path`；`store.ai_log` 优先于 `persistent.ai_seen`（按 200KB 封顶）。
- 降级三档：没 key 走本地模板，全流程照样可玩；单拍请求失败只在该拍降级并加顶部提示；正常走 AI。

## 运行

需要 Ren'Py 8.5.3 SDK，解压版即可，不用装进系统；SDK 自带 Python 3.12，不用另装 Python、pip 或第三方包，详见[依赖.md](依赖.md)。下面 `<SDK>` 是 SDK 目录，`<仓库>` 是仓库根目录。

```powershell
# 启动游戏
"<SDK>\renpy.exe" "<仓库>"

# 提交前检查
"<SDK>\lib\py3-windows-x86_64\python.exe" renpy.py "<仓库>" lint

# 生成 .rpyc
... renpy.py "<仓库>" compile

# 冒烟自测
... renpy.py "<仓库>" test

# 打包 Windows 版
... renpy.py "<仓库>" distribute
```

环境细节、沙箱里的存档目录设置、数值系统的函数说明，都在[开发环境说明.md](开发环境说明.md)。

## 约定

- 数值只走 `stats.rpy` 里的函数，剧情里不写 `$ study += 5`。
- 剧本先写成 markdown，标好 bg / bgm / sfx、选项和 Flag，再转 `.rpy`。
- key 一律英文小写 snake_case。改一个 key 要同时改三处：`变量命名规范_v1.md`、`stats.rpy`、回合事件表 §3 §5。
- 回合内的选择变量写成 `t<回合号>_<含义>`，值用小写英文，在 story 文件顶部 `default` 一次，不要放进 `flags`。`flags` 只放那 13 个正式 Flag。
- 主角名暂用 `XXX`，定稿后全仓替换一次。

## 还没定

校名、主角名、第三位女同学的名字。周墨的琴考到几级、停了多少年、旧琴是谁的。立绘要几个表情和姿势，素材从哪来。小游戏做选择题、实时操作还是只算数值。

AI 改造这边还没定的：模型和接口范围（只接一家还是多家）、每拍的 token 预算、随机化到什么程度（只换措辞还是连事件一起换）、AI 生成的文本进不进回滚录像、多结局的 AI 分支怎么和固定结局门槛对齐。
