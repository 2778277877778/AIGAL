# 高中校园物语

一个和女生说话就结巴的男生，用高一这一学年，帮一个把花藏在楼顶的女孩把花搬到了阳光下。

校园视觉小说，带一点轻生活模拟。引擎 Ren'Py，剧本写成 `.rpy`，先做 Windows。现在是 MIT 协议，简体中文，13+。

## 现在做到哪了

有一个能启动的 Ren'Py 骨架：标题界面、中文字体、1920×1080，四项数值和行动点的系统写在 `game/systems/stats.rpy`。八个月的剧本还没接进去，`game/story/` 是空的。

Demo 的体量是一个高一学年：9–12 月加 3–6 月，一个月一个回合，共 8 回合。寒假不铺开，一段蒙太奇带过去。一遍玩下来 20 到 60 分钟。完整版打算做到高三，10 小时以上，多角色多结局，现在只做周墨这一条线，结局两个。

参考过《火山的女儿》的日程和属性、《星露谷物语》的地图探索。

## 世界

深圳，一所寄宿高中。校名、区名、地铁线、地标都做了模糊处理。蓝白运动服，六人间，22:30 熄灯查寝，周末留校要登记。九月台风，三月回南天，六月暴雨，没有冬天。

## 怎么玩

一个月一个回合。月初到账 150 生活费，你有 3 点行动点，在地图上点节点跑；行动点用完或者自己结束本月，进月末的固定事件，然后结算、自动存档。

数值四项：学习、压力、体力、金钱。没有好感度，周墨那条线走到哪一步，看 Flag 和你在几个关键处怎么选。

地图节点是宿舍、教室、图书馆、食堂、小卖部、操场、艺术楼、天台、生物园，走动不花行动点。

考试有月考、期中、期末、学年期末，成绩 = 学习 + 随机(−5, +5)。小游戏目前想到篮球和刷题，暂定，不影响主线，失败有保底。

结局两个：TRUE「花开的时候」和 END「花期未至」。判定只看学习、压力和六个 Flag，其中一个 Flag 是主角在 T8 也填了物化地。不看任何好感数字。

数值都能调，口径写在 `高中校园物语/游戏设定总表_v2.md` §四 和 `高中校园物语/回合事件表_v2.md` §3。

## 还没统一的地方

第一幕全稿是按另一套设定写的，跟 v3.3 大纲打架：

- 周墨的秘密：大纲是花艺，因父母压力藏着；稿子里是钢琴。
- 行动点：大纲按月给 3 点，稿子按天给 3 点。
- 数值：稿子是 learning、stamina、mood、stress、money 五个，另外还有一个 `zm` 好感度。
- 配角：大纲是周子博、夏幸悠；稿子是贺鸣、江野、张浩。
- 班主任：大纲是教语文的曾老师，稿子是王老师。

两套只能留一套。先定花艺还是钢琴，把第一幕重写一版，之后才谈 `.rpy`。
