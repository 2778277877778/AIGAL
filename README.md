# 高中校园物语

一个和女生说话就结巴的男生，用高一这一学年，在学校最旧的那台琴旁边，把一个不敢再弹琴的女孩按回了琴凳。

校园视觉小说，带一点轻生活模拟。引擎 Ren'Py 8.x，简体中文，13+，首版只做 Windows。

## 现在的状态

工程能跑：标题、中文字体、1920×1080，四项数值和行动点左右都齐了，代码在 `game/systems/stats.rpy`。剧本还没接进去，`game/story/` 是空的。第一幕「见」的全稿已经按钢琴线写完，在 `高中校园物语/剧本_周墨线_第一幕_开学.md`，可以直接拆 `.rpy`。

Demo 做高一一年。9–12 月加 3–6 月，一个月一个回合，一共 8 个回合，寒假不铺开，一段蒙太奇带过，玩一遍 20 到 60 分钟。完整版打算做到高三，10 小时以上，多角色多结局；眼下只做周墨这一条线，两个结局。

参考过《火山的女儿》的日程和属性，还有《星露谷物语》的地图探索。

## 世界

深圳，一所寄宿高中。校名、区名、地铁线、地标都不出现。蓝白运动服，六人间，22:30 熄灯查寝，周末留校要登记，手机周日晚交、周五发，军训头一周不查。天气只用得上九月台风、三月回南天和六月暴雨，没有冬天。

学校有一间旧琴房，在艺术楼四楼走廊尽头，门锁坏着，平时堆旧谱架和体育器材。里面一台立式琴，音准早就偏了。整条线就是从这台琴开始的。

## 怎么玩

一个回合是一个月。月初到账 150 块生活费，给 3 点行动点，在地图上点节点跑；用完或者自己结束本月，就进月末的固定事件，结算完自动存档。

四项数值是学习、压力、体力、金钱。好感度删掉了，周墨走到哪一步，只看 Flag 和你在几个关键处怎么选。

节点有宿舍、教室、图书馆、食堂、小卖部、操场、艺术楼、旧琴房、礼堂，走动不花行动点。T5 琴房要清空，琴挪到礼堂后台，看琴的地方也跟着搬。

考试有月考、期中、期末、学年期末，成绩等于学习加一个 −5 到 +5 的随机数。小游戏先定篮球和跑操，刷题还在犹豫；都不影响主线，失败也有保底。

结局两个：TRUE 叫「最后一个音」，END 叫「琴盖没开」。判定看学习、压力，再加六个 Flag，其中之一是主角 T8 也填了史地政。任何好感数字都不看。

数值都能调，口径在 `高中校园物语/游戏设定总表_v2.md` 第四节和 `高中校园物语/回合事件表_v3.md` 第三节。
