# 高中校园物语

> 一个和女生说话就会打结的男生，用高一的八个月，帮一个把花藏在楼顶的女孩，把花开到阳光下。

校园视觉小说 + 轻生活模拟。引擎 **Ren'Py**，剧本格式 `.rpy`，首版 Windows。

## 世界

深圳，寄宿制高中，背景模糊化处理：不出现真实校名、区名、地铁线、地标。

校服是蓝白运动服；六人间、22:30 熄灯、查寝、周末留校登记。气候是九月台风、三月回南天、六月暴雨，没有冬天。

Demo 覆盖 9–12 月 + 3–6 月，共 8 个回合，寒假用一段蒙太奇带过。

---

## 玩法

- **回合 = 游戏月**：月初生活费 +150 → 3 点行动点在地图节点间点击 → 月末固定事件 → 结算并自动存档。
- **四项数值**：学习 / 压力 / 体力 / 金钱。**没有好感度**，周墨的关系只由 Flag 和关键选择推进。
- **地图节点**：宿舍、教室、图书馆、食堂、小卖部、操场、艺术楼、天台、生物园。点击移动，移动不消耗 AP。
- **小游戏**：篮球、刷题（暂定，不影响主线，失败有保底）。
- **考试**：月考、期中、期末、学年期末，成绩 = 学习 + 随机(−5, +5)。
- **结局两个**：TRUE「花开的时候」/ END「花期未至」。只看学习、压力和五个关键 Flag，不看任何好感数字。

数值全部可调，集中记录在 `游戏设定总表_v2.md` 第七节。

## 已知不一致（动代码前先定这个）

`剧本_周墨线_第一幕_开学.md` 用的是另一套设定，和 v3.3 大纲冲突：

| | v3.3 大纲 | 第一幕全稿 |
|---|---|---|
| 周墨的秘密 | 花艺（因父母压力隐藏） | 不再弹的琴（音乐） |
| 行动点 | 每月 3 点 | 每天 3 点 |
| 数值 | 学习 / 压力 / 体力 / 金钱 | learning / stamina / mood / stress / money + `zm` 好感度 |
| 配角 | 周子博、夏幸悠 | 贺鸣、江野、张浩 |
| 班主任 | 曾老师（语文） | 王老师（语文） |

两套只能留一套。建议先定周墨是花艺还是钢琴，再统一叙事，然后才开始写 `.rpy`。
