## 0. 先说三条结论

1. **当前工作区里没有"人物形象"，只有行为证据。** `游戏设定总表_v2.md` v2.1 明确把「外貌、性格、年龄、家庭、口癖」移出（§三 开头），大纲 v3.4 §1 也写「一律不写」。`characters.rpy` 一共 17 行、8 个 define（7 个有名角色，加 `inner` 独白）。
2. **真正的形象在 git 历史里。** `79d4456^:高中校园物语/角色设定_苏瑶.md` —— 女主旧名**苏瑶**，就是现在的**周墨**（大纲 v3.4「苏瑶→周墨」）。那份稿子有外观、四层性格、家庭创伤、台词库、礼物表、好感度、5 个结局，是**目前唯一一份成型的"人物形象"**。
3. **但它的骨架和当前版本冲突**，不能整份搬：好感度已删、花艺线→钢琴线、天台→旧琴房、5 结局→2 结局、反派线本版没有。所以 §4 把它拆成「可回收 / 需改写 / 已废」三栏。

**一句话**：要"提取"，先决定提哪一层。当前版是成品剧本的**行为基线**；苏瑶稿是半成品设定的**素材库**。两个都要，但必须分开存、分别标状态。

## 1. 提取提示词（可复用，剧本更新后重跑）

```text
你是《高中校园物语》的剧本编辑。任务：从本仓库（含 git 历史）提取人物特征，写成人物卡，供 AI 对话渲染使用。

【只做提取，不做创作】
1. 每一条都必须能在原文里找到依据，末尾标出处（相对路径:行号）。找不到就写进 pending，不许自己补。
2. 不许写外貌（身高、发型、脸、服装细节）。设定总表 v2.1 已把外貌移出，立绘后期补。
3. 不许用定性形容词当结论：「高冷」「温柔」「孤独」「坚强」「痞笑」。只写可观察的：台词、动作、反应、别人怎么评她。
4. 旁白的判断不算人物设定。原仓库本来就不许写「她其实也很想被理解」这种句子，别把它当依据。
5. 原文自相矛盾的地方，并列记录，不擅自统一。
6. 区分「她说的话」和「别人对她的评价」。评价只能进「他者视角」，不能进 speech。

【读取顺序】
1. game/story/characters.rpy —— 拿 id 白名单和显示名。
2. game/story/*.rpy —— 按 id 逐条搜台词，原样照抄，不改标点。
3. 高中校园物语/*.md —— 拿「已确认」列、关键场景、每个 Flag 对应的行为。
4. git 历史里的作废稿：git show 79d4456^:"高中校园物语/角色设定_苏瑶.md"，按「可回收 / 需改写 / 已废」三栏归档，不许直接并入正文卡。

【每个 id 输出这些字段】
id / 显示名 / 剧情功能 / confirmed（✅）/ speech 说话方式（🟡）/ lines 原文台词 3–8 条 /
habits 行为与身体反应（🟡）/ relations / state_by_turn 分拍状态（只有周墨需要）/ pending（⬜）/ evidence（出处）

【周墨额外要求】
按八拍（T1 见 … T8 选）给 state_by_turn：这一拍她在「慢热 / 装 / 害羞 / 颠」的哪一格，以及一句能直接照着写的动作约束。依据是游戏设定总表 附录 A。

【自检，全部通过才交】
□ 每条都有出处？　□ 混进形容词没有？　□ 补外貌没有？
□ pending 里的项有没有被偷偷填掉？　□ 每人至少 3 条原文台词？　□ 有没有把旁白当设定？
□ 有没有把苏瑶稿里已经作废的东西（好感度、礼物表、5 结局、天台）当现行设定？
```

**喂给 AI 时不用整卡**：每拍只拼 `speech + habits(2 条) + lines(2 条) + forbidden`，周墨再加 `state_by_turn[本拍]`，约 150–200 字够了。整卡塞进去会挤掉场景信息。

## 5. 要你决定的四件事

1. **苏瑶的外观要不要回收？** 这是全仓**唯一一份**成型的形象描述（黑长直低马尾／深棕眼／168cm／扣到最上／7 个表情）。设定总表 v2.1 把外貌标成「待你设计」，但立绘后期要用。回收＝省一轮设计；不回收＝等美术从零来。**我建议先存进 `人物卡` 的 `pending`，不主动写进剧本**——因为外貌进了 prompt 就会污染 AI 的台词，而台词不需要知道她穿什么。
2. **周墨的琴考到几级、停几年、旧琴是谁的？** README 和设定总表都还问着，这三个数直接影响 T3「初二停两年」和 T5「用了六年的节拍器」对不对得上。
3. **夏幸悠、孔子帆只做配角还是开线？** 现在两个人零台词零场景，`characters.rpy` 还没 id。要么给两句台词，要么 T4 孔子帆那个「听见琴声」改成旁白。
4. **苏瑶台词库要不要整批并进周墨？** 我倾向只并「日常短句」那 5–9 条，感情类的先不并——现在周墨的节奏是「每拍只露一句」，一并就稠了。
