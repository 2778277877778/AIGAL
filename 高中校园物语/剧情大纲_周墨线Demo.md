## 一句话

一个把成绩当成人质的女孩，在第一次月考拿下年级第一，然后意识到——她赢的那场考试，根本不是在考她。

## 主题

**被看见，比被夸奖重要。**

- 她从小到大只被夸，没被看见。
- 主角不夸她，只是看见了她。
- 所以结局的分歧不是"表不表白"，是"有没有人真的看见她"。

## 情绪曲线

```
好奇 ──→ 暖 ──→ 一点不对劲 ──→ 紧绷 ──→ 坍塌 ──→ 落定
```

# 第一幕 · 开学（Day 1–2）

**幕目标**：让玩家相信"这个班里有一个人，所有人都认识她，但没有一个人认识她"。

### 1. 序章 · 宿舍（Day 1 早）

主角是外校考进来的普通新生，住校。宿舍广播念分班名单，念到"周墨"时楼道安静了半秒，随即被宿管吼散。

- **作用**：先立传说，后见真人。玩家带着"她是谁"进教室。
- 室友贺鸣登场，开朗话多，负责把主角的"普通"垫出来。

### 2. 初遇 · 教室（Day 1 上午）

主角不懂领书流程，向她问路。她只给最短的答案，全程没抬头。

- 她的座位在**第一排最里面靠墙**。**整排第一排只有她一个人**——全班都往后退，只有她往前坐。
- 她旁边的位置一直空着，堆着旧作业本和两把倒扣的铁架椅子，她的书包挂在椅背上。
- 王老师当堂问"谁去坐周墨旁边那个位置"，没有人举手。
- **作用**：立距离；埋下全剧最重要的回收点（那个空位）。

### 3. 教学关 · 第一天可以自己安排（Day 2）

第一次给 3 个行动点、4 个可选地点，玩家一定选不完。**这是整部游戏的核心张力，不用旁白解释。**

四个地点各给一次反馈：

- **教室**：自习时她折回来，指出他卷子上一处公式符号写反了。她不说多余的话。
- **图书馆**：图书委员林诗语登场，极度紧张，道歉比说话多。
- **球场**：江野登场，拉他补位，教他投篮。
- **食堂**：听见隔桌两个人打赌"周墨这次肯定第一"。

- **作用**：教会玩法 + 三条配角线同时铺开。

### 4. 裂缝 · 教室夜（Day 2 晚）

晚自习后主角回教室拿笔袋。她一个人还在，桌上一个只咬了一口的便利店饭团，旁边保温杯掉漆、缠着透明胶带。

**三选一**：搭话 / 什么都不说拿了就走 / 悄悄留一瓶牛奶。

- **作用**：她第一次从"传说"变成"人"。三个选项都不扣分——第一幕的规则是"怎么做都不会错，但做得不一样，后面接到的台词不一样"。

# 第二幕 · 逼近（Day 3–12）

**幕目标**：让玩家以为自己在推进一段关系，其实是在积累"她敢不敢说"的资格。

结构是**日常循环 + 剧情触发点**，一共 8 个事件。

### 5. 讲题之夜（第 2 周）

晚自习后空教室，她给他讲一道压轴题，语气像在读说明书。

他低头看见她的错题本——页边空白处不是涂改，是一行行歪的五线谱。她"啪"地合上本子。

**三选一**：直接问 / 绕着问 / 提一句图书馆有音乐类的书。

- **作用**：秘密第一次露出一角。三种问法她反应完全不同——这是她的性格核心。

### 6. 饭钱（第 2 周）

承接第一幕：他给她买饭（或留牛奶）。第二天钱被原封不动退回，附一张便利贴，只有两个字"不用"。

但中午回教室，饭盒是空的。

- **作用**：她的人物说明书。一句话都不用解释。

### 7. 图书馆伏笔（第 1–2 周，2 场）

林诗语整理还书车时随口提到：周墨以前常借音乐类的书，最近不来了；书还回来的时候页边角都是软的，像被翻过很多遍。

说完她自己慌了，觉得不该说别人的事。

- **作用**：用第三者的嘴印证第 5 场，比主角自己发现更可信。

### 8. 球场伏笔（第 1–2 周，2 场）

周墨从球场边经过，**停下看了三秒**。江野喊她要不要一起，她说不了，走了。

江野等人走远才说：她初中来过一次，投了两个球就走了，投得还挺准。

- **作用**：她想玩，但不敢。为"她其实一直想碰那个东西"做第二层印证。

### 9. 贺鸣的暗恋（第 2–3 周，2 场）

两场，都不点破：

1. 贺鸣开始"顺路"找主角，话题总绕着周墨转，问"她好不好接近"。
2. 贺鸣塞给主角一个东西，让他帮忙转交。**不写是什么。** 主角既没转交，也没说破。

之后贺鸣再没提过。

- **作用**：给正篇留关系张力。Demo 里不解决、不解释，只要玩家记住"这个人有点在意"。

### 10. 王老师的班会（第 3 周）

月考动员班会上，王老师说：分数是路标，它告诉你走到了哪，不是告诉你该往哪走。

**关键调度**：周墨抱着作业本站在教室门口，听到一半，转身走了。

- **作用**：主题句由老师说出，被当事人当场拒绝。第三幕她会亲口把这句话撞回来。

### 11. 楼梯间的电话（第 3 周周五夜）★ 第二幕高潮

主角回教室拿东西，在两层之间的转角听见她打电话。没开灯。

他听到的（不完全、有断续）：月考会考好 / 琴房的钥匙你哪来的 / 我不管你怎么想的，等高考完再说 / 钥匙我明天过来拿 / 她只应了一声"嗯"。

挂断后她在原地站了很久，手在抖。转身看见他，第一反应是防御，问他"有事吗"。

**三选一**：说没事然后走开 / 直接说"你手在抖" / 什么都不说，去买瓶水回来放她手里。

- **注意**：这里只透露"琴"和"钥匙"，**不透露童年**。童年留到第三幕摊牌，一次说完。
- **作用**：玩家第一次知道真相的一半，并且知道"这件事不该由我替她说出去"。

### 12. 天台（第 3 周周末）

主角在天台找到她。她不说话，他也不问。两个人坐着。

她最后说了一句完全无关的话——问这地方能看到几颗星星。

- **作用**：陪伴的定调。这一场**不允许推进任何信息**，只允许两个人待在一起。

# 第三幕 · 月考（Day 13–15）

**幕目标**：让她赢，再让她发现自己赢的东西不是她要的。

### 13. 月考当天（Day 13）

一段叙事 + 一次小游戏（或一次简化选择）。

**考前的三选一**：提前在她桌上放一杯咖啡 / 多睡十分钟 / 去教室门口等她一起进考场。

- **作用**：考前一日的心意，成本很低的温柔。

### 14. 出成绩（Day 14）

成绩榜贴在走廊。周墨，年级第一。

全班鼓掌。有人在后面小声说"我就说她能第一，我押对了"。老师表扬她。

**她的表情和考砸了没有区别。**

核心细节：她把成绩单**对折，塞进书包最外层**——不是夹进书里，是最外层，随时会掉出来的那层。

- **作用**：反套路的高点。赢的人不快乐，而且没人注意到。这一幕是整部 Demo 的支点。

### 15. 摊牌 · 音乐教室门口（Day 14 傍晚）★ 最终选择

门锁着。她坐在门口台阶上。

这是全剧她说话的**唯一一次长篇**，因为只有这一次。内容四层：

1. 小学六年级，市里比赛，第二名。
2. 回家告诉父亲，父亲问的是"为什么不是第一"。从那以后她就不弹了，真的不弹了。
3. 这个月她又弹了，偷偷地弹，她觉得自己可以。
4. 钥匙明天被收走，而她连一句"不要"都说不出来。

最后她问了一句——她把王老师那句话说回来了：**我考第一，到底有什么用。**

**这里不给"安慰"选项，只给"动作"。最终三选一：**

1. 从书包里拿出一本空白五线谱本（考前在文具店买的，一直没说），放在她手里。
2. 说"你考了第一，挺好的"。
3. 什么都不说，坐下来，跟她一起坐在台阶上。

- **作用**：分歧点。第 1 项需要好感门槛，保证前面的投入有意义。

# 两个结局

## 结局 A「旁边的椅子」（圆满）

**触发**：选第 1 项，且之前至少达成"天台"或"说破"其中之一。

她收下本子，很久没说话。然后翻开第一页，在第一行画了一个音符，把本子抱在怀里。

**收尾**：第二天早自习，主角把桌子从最后一排靠窗——全班最好的位置——搬到第一排她旁边——全班唯一没人要的位置。旧作业本和倒扣的椅子被清走。她没说话，只是把笔袋往旁边挪了挪，腾出半个桌面。

**落点**：第一排，那天早上坐满了。

## 结局 B「对折的成绩单」（遗憾）

**触发**：选第 2 或第 3 项，或好感不足。

她听完，笑了一下。很轻，很标准，是那种"谢谢，我没事"的笑，说"你说得对"，然后先走了。主角想说什么，没说出来。

**收尾**：一个月后，第二次月考出成绩，她还是第一。她的座位被调到**第一排正中间**——从角落到正中，从没人注意到位居众目。主角坐在后面，只能看见她的背影，她再也没有回头。他想起那天傍晚她说过的话，想不起来是哪一句了。

---

## 两结局的设计原则

1. **B 不是"她讨厌你"。** 她什么都没失去，成绩、名次、位置全都更好了。她只是把那个"可能"关掉了。这是最有后劲的遗憾。
2. **两个结局都不出现告白。** 感情线停在"那一步有没有迈出去"，不是"有没有在一起"。这样正篇可以无缝接上高二的告白。
3. **判定用关键行为计数，不用纯数值。** Demo 太短，只刷好感度会让玩家觉得在刷分。判定：`gave_notebook` 为真，且 `rooftop`、`hand_shaking` 中至少一个为真。
