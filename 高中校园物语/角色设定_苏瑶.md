# 📚 角色深度设定：苏瑶

> **角色名**：苏瑶  
> **定位**：女主角1（学霸线）  
> **核心主题**：缺爱的完美主义者如何学会接受爱

---

## 🎭 角色核心

### 一句话定义
> "一个用成绩筑起高墙的女孩，墙内是一颗渴望被爱却害怕受伤的心。"

### 角色标签
`高冷学霸` `原生家庭创伤` `完美主义` `缺爱` `专一` `外冷内热`

---

## 👤 外观设计

### 基础形象

```
发型：黑色长直发，通常扎成低马尾，刘海整齐
眼睛：深棕色，眼神锐利而冷漠，认真时会微微眯起
皮肤：白皙，略显苍白（熬夜学习）
身材：纤细高挑（168cm），姿态端正
校服：整洁得体，一丝不苟，扣子扣到最上面
```

### 表情设定

| 表情 | 描述 | 触发场景 |
|------|------|----------|
| **默认** | 冷淡、面无表情 | 日常状态 |
| **专注** | 微微皱眉，眼神认真 | 学习、思考 |
| **微笑** | 嘴角微微上扬，很克制 | 对主角感到开心时 |
| **害羞** | 耳朵微红，眼神躲闪 | 被主角关心时 |
| **生气** | 眼神更冷，沉默不语 | 被误解或被侵犯边界时 |
| **脆弱** | 眼眶泛红，强忍泪水 | 压力爆发、回忆创伤时 |
| **开心** | 罕见的真正笑容，眼睛弯成月牙 | 极少数放松的时刻 |

### 便装风格

- **日常**：简约深色系，黑色/深蓝/灰色为主
- **居家**：宽松的旧T恤（在家才穿，不愿让别人看到）
- **特殊场合**：偶尔会穿主角送的衣服（关系亲密后）

## 🧠 性格深度分析

### 性格层次图

```
┌─────────────────────────────────────┐
│  第一层：防御外壳                    │
│  高冷、疏离、完美主义、控制欲        │
├─────────────────────────────────────┤
│  第二层：保护机制                    │
│  独立、逞强、压抑情感、回避亲密      │
├─────────────────────────────────────┤
│  第三层：真实自我                    │
│  温柔、细腻、渴望爱、害怕被抛弃      │
├─────────────────────────────────────┤
│  第四层：核心创伤                    │
│  不够好、不值得被爱、必须完美才能获得认可│
└─────────────────────────────────────┘
```

### 性格特质详解

#### 1. 完美主义

**表现**：
- 成绩必须年级第一，否则会极度焦虑
- 作业必须无涂改，字迹工整
- 物品摆放必须整齐，不能有丝毫混乱
- 计划被打乱会感到不安

**根源**：
- 父亲从小灌输"只有第一才有价值"的观念
- 将自我价值与成绩完全绑定
- 害怕失败，因为失败意味着"不值得被爱"

**与主角的互动**：
- 初期：看到主角轻松学习会感到不屑
- 中期：开始羡慕主角的心态，但不愿承认
- 后期：被主角影响，学会放松一点点

#### 2. 缺爱与渴望

**表现**：
- 对别人的善意会感到困惑和不安
- 收到礼物会不知所措，但内心很开心
- 会偷偷记住主角说过的每一句话
- 夜晚独自一人时会感到孤独

**根源**：
- 父亲只关心成绩，从不表达爱
- 母亲情感淡漠，无法给予温暖
- 从未体验过无条件的爱

**与主角的互动**：
- 初期：抗拒主角的关心，觉得"他为什么对我好？"
- 中期：开始期待主角的出现，但不敢表现出来
- 后期：学会接受爱，但仍然会患得患失

#### 3. 专一与重视

**表现**：
- 一旦认定某人，会全心全意对待
- 会记住主角的所有喜好和习惯
- 在主角需要帮助时，会放下一切来帮忙
- 对感情非常认真，不会轻易开始，也不会轻易结束

**根源**：
- 内心极度缺乏安全感，害怕失去
- 将感情视为珍贵的东西，不愿随意给予
- 一旦付出，就会倾尽所有

**与主角的互动**：
- 初期：保持距离，观察主角是否值得信任
- 中期：开始在意主角，但嘴上不承认
- 后期：明确感情后，会变得非常粘人（私下）

## 💭 心理状态

### 焦虑症状

| 症状 | 表现 |
|------|------|
| **考试焦虑** | 考前失眠、食欲不振、手抖 |
| **社交焦虑** | 在人群中感到不安，害怕被评判 |
| **完美主义焦虑** | 一点小错误就会自责很久 |

### 应对机制

| 机制 | 表现 |
|------|------|
| **压抑** | 不让自己哭泣，认为软弱是可耻的 |
| **控制** | 控制一切能控制的东西（成绩、物品摆放） |
| **回避** | 回避亲密关系，避免受伤 |
| **转移** | 用学习来转移注意力，不让自己想太多 |

### 隐藏的秘密

1. **失眠**：经常失眠，靠咖啡维持精力
2. **天台哭泣**：偶尔会在天台独自哭泣
3. **日记**：写日记记录心情，但从不让任何人看到
4. **自我怀疑**：内心深处觉得自己不够好

## 💕 感情线设计

### 感情发展阶段

#### 阶段1：陌生期（高一开学-10月）

**状态**：完全陌生，保持距离

**表现**：
- 不会主动与主角说话
- 对主角的接近感到警惕
- 认为主角和其他人一样，只是好奇

**关键对话**：
```
主角："苏瑶，这道题你会吗？"
苏瑶："...（看了一眼）答案是C。"
主角："能教教我吗？"
苏瑶："...看书上的例题。"
（转身离开）
```

#### 阶段2：观察期（10月-12月）

**状态**：开始注意主角，但仍保持距离

**表现**：
- 会偷偷观察主角
- 对主角的帮助感到困惑
- 开始记住主角的习惯

**关键事件**：雨天共伞（第一次感到温暖）

**关键对话**：
```
苏瑶："...你为什么对我好？"
主角："因为我们是同学啊。"
苏瑶："...只是同学吗？"
主角："嗯...也是朋友吧。"
苏瑶："...（低头）我不需要朋友。"
（但第二天，她主动帮主角占了座位）
```

#### 阶段3：信任期（高一下学期）

**状态**：开始信任主角，放下防备

**表现**：
- 会主动找主角说话
- 在主角面前展露真实情绪
- 开始期待与主角的相处

**关键事件**：天台的秘密（主角发现她哭泣）

**关键对话**：
```
苏瑶："...你看到了？"
主角："嗯。"
苏瑶："...你会告诉别人吗？"
主角："不会。"
苏瑶："...为什么？"
主角："因为这是你的秘密。"
苏瑶："...（流泪）我好累..."
主角："我知道。"
（第一次在别人面前哭泣）
```

#### 阶段4：依赖期（高二）

**状态**：开始依赖主角，但内心不安

**表现**：
- 会主动找主角帮忙
- 在主角面前变得柔软
- 但会担心主角会不会离开

**关键事件**：生日惊喜

**关键对话**：
```
苏瑶："...你怎么知道今天是我生日？"
主角："我问过老师。"
苏瑶："...（愣住）从来没有人..."
主角："生日快乐，苏瑶。"
苏瑶："...（流泪）谢谢..."
（第一次收到生日祝福）
```

#### 阶段5：明确期（高二下学期-高三）

**状态**：明确感情，但面临抉择

**表现**：
- 会吃醋（虽然不愿承认）
- 在主角面前变得更自然
- 但会担心影响学习

**关键事件**：文化祭后的表白

**关键对话**：
```
苏瑶："...林晨。"
主角："嗯？"
苏瑶："...我...我好像..."
主角："好像什么？"
苏瑶："...好像喜欢你。"
（声音小到几乎听不见）
```

#### 阶段6：危机期（高三）

**状态**：高考压力与感情的冲突

**表现**：
- 焦虑加重，可能会疏远主角
- 担心感情会影响成绩
- 需要主角的支持和理解

**关键事件**：考前崩溃

**关键对话**：
```
苏瑶："...我们不要见面了。"
主角："为什么？"
苏瑶："...会影响学习。"
主角："真的只是因为学习吗？"
苏瑶："...（沉默）我害怕。"
主角："害怕什么？"
苏瑶："...害怕你会离开。"
```
